# 陰影之下

以澳門街區為背景的劇情調查冒險遊戲。教學、第一至第三幕共用同一世界、NPC、傳送碑與地圖介面。

## 遊玩

GitHub Pages 自動部署後，開啟本倉庫 Settings → Pages 顯示的網站。第一次請從首頁開始，完成第一幕領取獬豸，再繼續第二幕領取白澤。已到訪街區可從地圖選擇傳送；幕間不會自動移動主角。

- WASD／方向鍵：走路；滑鼠移動：朝向；點地面：行走。
- E／空白鍵：互動；M：地圖；L：線索。手機使用畫面上的搖桿與按鈕。
- 第一幕六顆明鑑果對應獬豸；第二幕新開六顆證言莓對應白澤；第三幕新開六顆守界梨對應貔貅。每顆果實都有一道不同的精靈屬性題。
- 三種果實、題目、背包與成長進度獨立。果實可先收集，完成對應章節領取精靈後才能投餵。各自投餵3次進入成長體，6次進入守護體。
- 果實在可行走且能從街區出生點抵達的位置隨機生成，避開人物、傳送碑及其他果實；位置隨存檔保留。新章節會增加新精靈果實，未拾取的舊果實保持存在。
- 底層果實池共36顆（六種精靈各六顆）；目前開放三幕，最多18顆未領取果實同時出現，後三幕的果實尚未開放。
- 未領取精靈時，果實顯示「神秘的果實 · 用途未知」並提供外觀描述；領取後才顯示對應精靈及果實名稱。
- 每種精靈的第1–2題為基礎辨識、第3–4題為情境核對、第5–6題為綜合判斷。正確答案位置隨機；答錯後所有果實題共用30秒冷卻，刷新也不會清除。果實仍留在原地。
- 第二幕四項調查完成後結案，閱讀規則再領白澤，返回街區可見白澤跟隨。
- 簡繁中文、自命名、六區配樂；進度保存在目前瀏覽器。不同網址的存檔不互通。

## 本機開發

需要 Node.js 22。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

部署檔位於 `dist/`，可上傳到靜態網站。推送 `main` 會執行 `.github/workflows/pages.yml` 測試、構建並部署。

第三幕《禮包裡的名字》：在舊城核對禮包來源，至山坡核對收件記錄，再回聯署比對價值、審批往來與利益邊界。四份記錄須依序調查，閱讀結案規則後領取貔貅。幕間保留主角位置。

舊版共用零食及獬豸成長進度會遷移至獬豸專屬背包；新增白澤與貔貅果實從零開始。既有自動測試不代表所有劇情與手機操作已完成實機驗收。

開場以蓉姐邀請見習生加入CCAC、報到與同行展開；具體案件放在各幕開始時介紹。角色各方向的步態放慢，寵物在縱向移動時也持續播放步態，主角停止時停止踏步。
