# 陰影之下

以澳門街區為背景的六幕劇情調查遊戲。教學及第一至第六幕使用同一組原有街區、NPC、12個傳送碑及右上角地圖；幕間保留主角位置，由玩家自己前往下一個調查地點。

## 開啟與存檔

[線上遊玩](https://zaccccccccccccccccccccccccccccccccccccc.github.io/shadow-beneath-game/)

- 「新遊戲 · 從教學開始」先備份上一份遊戲進度，再開始無神獸的教學。
- 「繼續調查 · 讀取存檔」保留位置、已取得夥伴、線索、果實、投餵和答錯冷卻。
- 存檔只屬於目前瀏覽器及網站網址；無帳戶伺服器。私人瀏覽或清除網站資料會影響存檔。

## 操作

- WASD／方向鍵移動；滑鼠位置控制朝向；點地面尋路。移動和朝向可各自操作。
- E／空格交談與使用傳送碑；L開線索簿；M開原有街區地圖；H求救引路；P開精靈檔案。
- 求救每幕3次，只顯示頭頂黃色箭頭及地面虛線，不代替走路或選擇對話。
- 未到訪街區先沿傳送碑前往；到訪後可從地圖選擇快速返回。下一幕不自動把角色搬到學校。
- 手機建議橫向；提供搖桿、互動、求救、線索、地圖和精靈按鈕。對話結束需點對話框中的按鈕。
- 開場自動換頁；可開啟「中文語音」、下一頁或跳過。語音使用裝置的中文語音引擎，無可用聲音時仍可閱讀和跳過。

## 六幕連續檔案

| 幕 | 情景 | 主要核對項目 | 領取精靈 |
|---|---|---|---|
| 教學＋第一幕《看見》 | 在據點學習操作，沿舊城、海邊和校園核對初始線索 | 移動、引路、人物、案卷、L/M；會面、登記、帳目和缺頁 | 獬豸 · 明辨曲直 |
| 第二幕《帳本的空白頁》 | 從缺頁繼續追查社團活動費 | 帳簿→物資簽收→線人會面→茶館登記，4項調查 | 白澤 · 求證核實 |
| 第三幕《禮包裡的名字》 | 廠商禮包與審批關聯 | 來源→收件→價值及審批→利益邊界，4項調查 | 貔貅 · 守住邊界 |
| 第四幕《朋友價》 | 翻修報價和另行結算差額 | 報價→合同→工程量材料→付款→覆核，5項調查 | 麒麟 · 克制私欲 |
| 第五幕《實習費》 | 招聘介紹費與名額承諾 | 招聘→碼頭見聞→聊天→付款→權限→交接，6項調查 | 玄武 · 守責到底 |
| 第六幕《沉默的申請》 | 陳伯的申請與流轉缺口 | 收件→流轉→同類時程→催辦→責任界線→六幕關係網，6項調查 | 青龍 · 公開透明 |

每幕均先顯示調查覆核及法律學習，再由玩家按鈕領獎；之後介紹下一幕。終局回顧六份檔案，主線完成後仍可探索及培育精靈。

## 果實、答題與成長

每幕增加該精靈的6顆果實，先前未拾取的果實保留；第六幕最多36顆未收集果實。位置依存檔隨機，經路徑檢查，不把舊果實改成新種類。

| 精靈 | 專屬果實 | 三階形態 |
|---|---|---|
| 獬豸 | 明鑑果 | 幼靈→巡查靈→守正靈 |
| 白澤 | 證言莓 | 初識→博聞→鑑證 |
| 貔貅 | 守界梨 | 納福→知止→鎮界 |
| 麒麟 | 清心蓮果 | 微光→仁心→瑞行 |
| 玄武 | 負卷豆 | 守卷→負甲→定責 |
| 青龍 | 昭明柑 | 初霽→行雲→昭明 |

走近果實點擊答題；答對才把果實放進對應背包，地面只移除那一顆。每隻6道專屬屬性題，前2題基礎、中2題情境、後2題綜合。答錯共享30秒冷卻，刷新不能跳過，果實不會消失。

尚未領取精靈時顯示「神秘的果實 · 用途未知」及外觀描述，可先存入背包，領獎後才可投餵。每顆只供對應精靈：投餵3次成長、6次守護，外觀和尺寸都改變；六隻都升至守護共需答對36題並投餵36次。各自進度獨立。

## 法律學習來源

遊戲採澳門背景，六幕結算提供澳門法規的學習線索及官方來源按鈕。疑點、帳目異常或收費不直接等於犯罪；身份、權限、目的、財物及完整證據仍須核實。本遊戲不把教學選項當成個案定罪或量刑。

- [澳門法院：公務賄賂相關規則](https://www.court.gov.mo/sentence/zh/233)
- [廉政公署：公務人員廉潔操守指引](https://www.ccac.org.mo/pdf/cn/guide/G-CN-ALL.pdf)
- [廉政公署：廉潔營商指引](https://www.ccac.org.mo/pdf/cn/book/gl2012.pdf)
- [廉政公署：私營部門賄賂常見問題](https://www.ccac.org.mo/PrivSec/pdf/cn/faq_cn.pdf)
- [廉政公署：濫權謀私須負刑責](https://www.ccac.org.mo/tc/promotion_n_education_media_knowledge_details/article/kbafv7bp.html)

## 開發與驗證

需要Node.js22。

```sh
npm ci
npm test
npm run build
npm run dev
```

`dist/`為可部署的靜態網站，資源使用相對路徑。推送main後，GitHub Actions測試、構建並部署Pages。`tests/browser/`保留隔離Chrome沙盒及實際操作腳本，詳見該目錄README；測試依賴置於忽略的outputs，未加入正式遊戲。
