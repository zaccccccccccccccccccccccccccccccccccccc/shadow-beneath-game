# 《陰影之下》六幕連續版交付與驗收

本版完成教學及第一至第六幕，採用原有世界與地圖。線上入口：[開始調查](https://zaccccccccccccccccccccccccccccccccccccc.github.io/shadow-beneath-game/)。玩法及每幕情景見倉庫README。

## 已完成

1. 連接《看見》《帳本的空白頁》《禮包裡的名字》《朋友價》《實習費》《沉默的申請》，最後進入六幕關係網覆核。幕間保留角色位置、線索、背包及已領取精靈。
2. 六幕分別獎勵獬豸、白澤、貔貅、麒麟、玄武、青龍。每幕先閱讀規則，再由玩家領獎；新遊戲從無精靈教學開始。
3. 每種精靈6顆獨立果實、6道屬性題，最多36顆；舊果實不被替換。未領精靈時顯示神秘外觀描述，領取後識別用途。
4. 答對入背包，答錯30秒冷卻且保留果實。各自投餵3次成長、6次守護，圖片及尺寸改變；投餵有果實飛入和愛心動效。
5. 夥伴檔案可用P或手機「精靈」開啟；線索簿分頁，任務清單可滾動。H每幕3次引路，只畫頭頂箭頭與地面虛線，不代替行走和對話選擇。
6. 保持主角既有尺寸，調整NPC顯示比例並以腳底對齊；NPC對話採半身裁切。正／背向兩格步態每96像素換格，與側向四格每48像素的完整步幅同為192像素。
7. 邊緣角色經過任務面板或小地圖後方時，介面暫淡出並允許點地面；不透明介面則優先接收操作。人物與傳送碑優先於跟隨精靈，避免點不到目的地。
8. 開場五段自動敘事，可開關裝置中文語音、下一頁及跳過；跳過或離場會取消朗讀、計時與動畫。
9. 各幕結算補充澳門法規學習及官方來源入口，保留條件與證據要求，避免把疑點直接當作定罪或量刑。

## 本輪修復的具體故障

- 序幕跳過後，清理程式讀取已銷毀攝影機而黑屏。
- 快速按M／L時，按鍵在下一影格前放開，導致操作遺失。
- 第二幕最後對話按Esc會連剛打開的結算頁一起關掉，無法領白澤。
- 伙伴遮住傳送碑，或頂端傳送碑被小地圖截獲點擊。
- 舊尋路未清空，交談後或跨幕仍會繼續移動。
- 異常第三幕存檔跳過前置步驟，造成永遠不能完成；恢復時改採有效有序前綴。
- 後幕獎勵標記不能繞過缺少的前幕；新遊戲亦清除後三幕狀態並備份上一個遊戲存檔。
- 提示條不再覆蓋結案規則頁；蓉姐稱呼與廉署用字統一。

## 遊玩及驗收邊界

- 新開體驗選「新遊戲 · 從教學開始」；舊玩家要保留原進度則選「繼續調查」。
- 語音使用瀏覽器／裝置提供的中文聲音，並非另製錄音配音；測試確認開關及跳過取消，未以無頭瀏覽器證明實際聽感。
- 手機操作已作瀏覽器觸控模擬；實體iPhone／Safari及不同效能手機仍須在決賽前復核。
- 存檔存在目前瀏覽器，沒有新增註冊伺服器或跨裝置帳戶同步。
- 路由測試證明所列碰撞矩形與點位可達，不能取代對每一處背景畫面透視邊緣的美術驗收。

## 可複現命令

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npm.cmd install --prefix outputs/browser-deps playwright --no-save --package-lock=false
node tests/browser/run.mjs
node tests/browser/campaign.mjs
node tests/browser/species-growth.mjs
node tests/browser/production-mobile.mjs
node tests/browser/hud-save-guards.mjs
```

建置結果在`dist/`，可上傳靜態網站。GitHub Pages以倉庫工作流程自動部署；正式網址另以隔離瀏覽器重新確認新遊戲入口和實際資源載入。
