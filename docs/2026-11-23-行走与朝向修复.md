# 行走與朝向修復 · 2026-11-23

## 實際故障及修復

- 方向鍵未註冊：同時註冊 WASD 與四個方向鍵。
- 到達終點轉正面、擦牆時朝向錯誤：以實際位移決定無鼠標瞄準時的朝向；零位移保留方向。
- 尋路提前約24px停下：每個節點距離≤2px才前進，補上同一尋路網格內的短距離點擊。
- 任務欄、地圖、求救等視窗的指標移動洩漏到角色：原生滑鼠移動只接受遊戲地面，遮罩與按鈕使用各自的實際範圍。
- 鼠標瞄準、鍵盤位移保持獨立，點地面後再按WASD仍保留鼠標瞄準；觸控搖桿接管時清除舊鼠標瞄準。
- 傳送後沿用上一張圖的路線：傳送前清除舊路線、待互動目標與瞄準。
- 側走四幀頭部位置相差約11個顯示像素：依原圖透明像素邊界補償每幀X錨點，左右鏡像對稱；Y補償4px以銜接站立腳底。
- 移除未被主遊戲使用、方向映射錯誤的舊動畫測試，改測主遊戲實際使用的四幀與192px完整步週期。

## 驗證方法與範圍

`npm.cmd test`、`npm.cmd run build`；Chrome真實鍵盤、滑鼠及觸控腳本：

- `tests/browser/movement-regression.mjs`：19項移動回歸；直接讀取原圖片alpha邊界與渲染偏移驗證四幀對齊，截圖留在`outputs/movement-regression/`。
- `tests/browser/campaign.mjs`：空存檔從教學連續走完六幕，真實尋路、交談、獎勵及重載。
- `tests/browser/production-mobile.mjs`：正式入口手機橫屏與直屏、搖桿及結束交談等9項。
- `tests/browser/public-smoke.mjs`：部署後公開網址的新遊戲、方向鍵位移及面板。

未改動地圖、道路、碰撞地形、NPC座標或傳送點。上述回歸覆蓋已復現輸入故障；不等同於逐像素檢查全部地圖邊緣。
